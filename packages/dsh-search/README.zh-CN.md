# 搜索

[English](README.md) | 中文

用你启用的后端搜索网页，开启前即可看到每个后端的价格。所有后端默认关闭，需要密钥的模式可能产生费用。

## 功能

- 一次搜索覆盖你启用的所有后端，每个后端的访问模式由你选定。
- 每个后端在启用前就标明费用档，以及价格与额度的来源。
- 测试单个后端，并在设置页里查看最近的调用结果。
- 可通过 HTTP、浏览器或服务商抓取页面，并设置回退规则。
- 导入、导出设置，导出的文件不含密钥。

## 安装

```sh
dsh plugin add @nite07/dsh-search
```

需要 DeepSeek Harness 0.2.2-rc.4 或更高的 0.2 版本，且 DSH 所在环境需要 Node.js 22 或更高版本。重启 DSH 后，打开 **设置 → 搜索**。

## 使用

1. 在「搜索」页签启用一个后端，先看这一行的价格。
2. 所选模式需要密钥时，在服务商卡片里填写。密钥只保存一次，之后不再显示。
3. 点「保存设置」。
4. 如果页面提示当前搜索源不是本插件，点「设为网页搜索来源」。
5. 让 Agent 搜索。

Agent 可以：

- 搜索你启用的所有后端；
- 启用对应后端后，读取一条 X 推文、一篇小红书笔记或一个 Reddit 帖子；
- 打开「允许使用 web_extract」后，把单个页面抓取为 Markdown 或 HTML。

## 设置

设置页位于 **设置 → 搜索**，每个页签负责一类配置。

| 页签 | 用途 |
| --- | --- |
| **搜索行为** | 查询参数、去重方式与搜索工具开关 |
| **稳定性** | 重试、熔断、缓存与诊断保留量 |
| **试搜与诊断** | 测试后端、查看最近结果、导入导出与恢复默认值 |
| **搜索** | 后端、访问模式、价格、端点与凭证 |
| **浏览器** | 共享浏览器端点、令牌、登录态文件、读取超时与读取上限 |
| **页面抓取** | 抓取路由、回退规则、服务商、超时与输出上限 |

## 限制

- 某个后端失败时，结果里会说明，不会改用另一个后端顶替。
- 需要密钥的模式可能产生费用，开启重试或运行测试同样可能计费。
- 浏览器抓取和小红书都使用你自己托管的浏览器。小红书还需要你自己登录，连接检查成功不代表已登录。
- 部分网站会拒绝自动访问，即使配置了抓取路由也可能失败。
