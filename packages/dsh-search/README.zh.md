给 DeepSeek Harness 用的多后端网页搜索：24 家搜索服务，逐个开关，每个都明确选定接入模式、标明费用档。

## 安装

```sh
dsh plugin add @nite07/dsh-search
dsh --profile web   # 或者用你自己的方式重启 dsh web
```

也可以在 **设置 → 插件 → 添加插件** 里安装。

装完把它设为搜索来源：打开 **设置 → 网页搜索**，如果页面提示当前不是本插件，点「**设为网页搜索来源**」。

## 第一次搜索

1. 打开 **设置 → 网页搜索**
2. 在「搜索」页签里挑一个不需要账号的启用：Keenable、AnySearch、Exa、Parallel、You.com、DuckDuckGo 或 Reddit
3. 看一眼那一行的费用说明，点「保存设置」
4. 让 agent 搜点东西

所有后端默认关闭，不保存就一个请求都不会发出。想绕开 agent 单独验某一家通不通，用「试搜与诊断」页签：它明确发一次真实请求，把结果和失败原因原样显示出来。

## 加 Key

`key` 或 `session` 模式需要凭证。在服务商卡片上填入并保存即可，凭证保存在 DSH 凭据库中，不会写入配置文件。

搜索和页面抓取共用同一家服务商的已保存密钥，在「搜索」或「页面抓取」页签都能填写；两者的接入模式和用量上限分别设置。

## 后端与费用

列表按**每家最便宜的用法**分组，所以有完全免费路径的永远排在最前面。每行用 chip 标出**所有**模式各自的费用档，当前选中的那个高亮。

| 分组 | 有哪些 | 说明 |
| --- | --- | --- |
| **有完全免费的用法** | Keenable、AnySearch、Exa、Parallel、You.com、DuckDuckGo、Reddit | 不用注册、不用 Key，开箱可用 |
| **自带账号** | X | 用你自己 X 网页端的 cookie，不花钱，但 X 改动页面里内嵌的接口时会失效 |
| **自托管** | SearXNG、open-websearch、小红书（Xiaohongshu） | 自己跑服务，额度由你自己定；小红书走的是你自己托管的浏览器 |
| **免费额度** | Linkup、Tavily、Brave、知乎（网页/站内）、百度、豆包 | 注册拿 Key，额度内免费 |
| **试用额度** | Serpex | 一次性试用额度，用完转付费 |
| **付费** | Mojeek、Anthropic、OpenAI、DeepSeek、腾讯 WSA | 按量收费，开之前先看单价 |

- 默认**全部关闭**，一个都不会自动启用
- 各家的具体额度、单价、来源链接和核实日期见 [docs/BACKENDS.md](docs/BACKENDS.md)

## 小红书

通过自己托管并登录的浏览器搜索小红书、读取笔记。插件不按次收费，你只需承担运行浏览器的成本。

1. 按 [packages/core/image](../core/image/README.zh.md) 起浏览器容器，启动日志会打印端点和令牌
2. 打开 `http://<host>:6080/vnc.html`，在那扇已经开着的窗口里登录小红书。容器每分钟把登录态写进磁盘
3. 打开 **设置 → 网页搜索 → 浏览器**，填共享端点（`ws://<host>:3000/ws`）、可选的会话文件、读取超时与同站点并发读取数，再把启动日志里的令牌填进「端点令牌」。这个 Tab 会列出所有依赖它的已启用功能
4. 在 **搜索** Tab 把小红书后端的模式设为 browser，启用并保存。保存前会检查端点与令牌；被拒绝时到「浏览器」Tab 点 **检查连接** 看具体原因

端点令牌用于保护浏览器访问，不代表已经登录小红书。如果填写会话文件，请使用容器写入的那个文件。登录需要在 noVNC 中完成，插件不能代你登录。

同站点并发读取数限制同一个站点上的浏览器读取数量；「搜索行为」里的并行后端数则限制一次搜索同时查询几家服务商。

## 工具

- `web_search` — 上面说的多后端搜索。
- `web_search_plus` — 按本次调用指定搜索策略：`backends`（从已启用里挑选；一个 id 表示单后端，多个 id 表示并行）、`allBackends` + `exclude`（全用但排掉几家）、`compact`（精简结果，保留来源后端）和 `maxResults`。只影响这一次调用，不改配置；没启用的后端会被明确告知而不是被悄悄忽略，实际用了哪些也会回显。可在设置里关闭。
- `x_thread` — 读一条 X 推文及其回复；需要 X 后端处于会话模式，深度、回复条数和字符预算都有上限。
- `xiaohongshu_note` — 读取一篇小红书笔记的正文、作者、互动数据、标签和配图，也可读取一级评论。传入分享链接（带有读取所需的 token）或此前搜索返回的笔记 id；需要小红书后端处于 browser 模式，且已配置共享浏览器端点。
- `reddit_thread` — 读取某个 Reddit 帖子及其评论树；按深度、评论条数和字符预算截断。
- `backend_status` — 一眼看清现在开了什么：启用了哪些后端、各自的模式、费用档、凭证是否就位（只报有没有，不回值）、今天调了几次、上次成功还是失败以及失败原因，另外告诉你插件是不是当前的搜索来源。传一个后端 id 可以看它的全部模式、额度和可选项。只读，不会启用任何东西，也不花钱。
- `search_manage` — 从 agent 侧查看或修改本插件的设置和凭证，包括共享浏览器令牌（`scope: browser`）。也可手动测试页面抓取（`action: "fetch-test"`，指定 `url` 和 `format`）。
- `web_extract` — 把单个页面抓取为 Markdown 或 HTML。**默认关闭**，在「页面抓取」页签打开「允许使用 web_extract」后，agent 才能使用。调用时必填 `url` 和 `format`（`markdown` 或 `html`），其余使用已保存的抓取设置。返回的页面内容应视为不可信数据。

## 页面抓取

抓取单个 URL，返回适合阅读的 **Markdown**，或用于查看页面结构的 **HTML**。支持直接 HTTP、共享浏览器和抓取服务商三种方式。在 **设置 → 网页搜索 → 页面抓取** 中选择要启用的方式，调整顺序和回退规则。

1. 至少启用一种抓取方式。使用浏览器时，先在「浏览器」页签配置共享端点和令牌；使用服务商时，选择服务商和抓取接入模式，需要 Key 的模式还要填写凭证。
2. 检查费用、超时、输出上限和网络访问设置，再点「保存设置」。
3. 在页面抓取测试中输入 URL，选择 **Markdown** 或 **HTML**，按已保存的设置测试。需要让 agent 抓取页面时，再打开「允许使用 web_extract」。

在设置页选择服务商，并查看支持的格式和费用。部分模式无需 API Key，其余模式应先填写凭证。
搜索和抓取共用同一家服务商的密钥。需要 JavaScript 的页面可以使用共享浏览器，但不保证能访问所有受保护页面。

**测试会发出真实网络请求，服务商可能收费。**

## 设置页结构

切换页签会保留草稿，点击「保存设置」后才会应用修改。

| 页签 | 可以设置什么 |
| --- | --- |
| **搜索行为** | 查询形态、安全搜索、语言与地区、agent 工具开关 |
| **可靠性** | 重试、熔断、缓存与诊断保留量 |
| **测试与诊断** | 按已保存设置测试后端、查看最近结果、导入导出 |
| **搜索** | 搜索后端、接入模式、费用、端点与凭证 |
| **浏览器** | 共享浏览器端点、端点令牌、会话文件、读取上限与依赖浏览器的功能 |
| **页面抓取** | 抓取方式、回退规则、服务商、超时、输出上限与浏览器选项 |

## 保存与浏览器检查

点击「保存设置」后，请查看保存结果。设置有误时，点击问题后的链接前往修改，草稿会保留。如果另一个窗口先保存了，请读取最新设置，再重新应用修改。结果无法确认时，先检查已保存的设置，再决定是否重试。

启用小红书搜索或浏览器页面抓取后，保存时会检查浏览器端点和令牌。保存前也可以在「浏览器」页签点「检查连接」。检查成功只代表连接可用，**不代表**已经登录网站。

搜索优先使用共享浏览器端点，未填写时才使用后端自己的端点；浏览器页面抓取必须使用共享端点。浏览器暂时不可用时，可以先关闭所有依赖浏览器的功能以离线保存，修好连接后再重新启用。

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 搜不出东西 | 后端在你保存之前都是关闭的。去「搜索」页签启用一家再保存。 |
| 小红书报未登录 | 浏览器容器的登录态丢了。打开 noVNC 页面重新登录，下次读取会重新加载会话文件。 |
| 小红书报没有端点 | 到「浏览器」Tab 填共享端点，或在搜索卡片里填该后端自己的端点。 |
| 某家返回限流 | 那家拒绝了这次请求。等一会儿，或在它那一行调低每分钟上限。 |
| 提示「配置版本冲突」 | 另一个窗口先保存了。刷新页面后重新提交；草稿会保留。 |
| 保存被拒绝：浏览器端点不可达或令牌被拒 | 保存前的校验无法验证已启用的浏览器依赖。到「浏览器」Tab 点 **检查连接**，修好端点或令牌；或者先关闭所有浏览器相关功能离线保存。 |
| 提示设置有误 | 点击问题后的修复链接，修改对应设置后重新保存。 |
