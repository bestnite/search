# dsh-search

[English](README.md) | 中文

给 DeepSeek Harness 用的多后端网页搜索：24 家搜索服务，逐个开关，每个都明确选定接入模式、标明费用档。

## 安装

```sh
dsh plugin add @nite07/dsh-search
dsh --profile web   # 或者用你自己的方式重启 dsh web
```

也可以在 **设置 → 插件 → 添加插件** 里安装。

装完把它设为搜索来源：打开 **设置 → 网页搜索**，如果页面提示当前不是本插件，点「**设为网页搜索来源**」。

## 第一次搜索

1. 打开 **设置 → 网页搜索**
2. 在「搜索后端」页签里挑一个不需要账号的启用：Keenable、AnySearch、Exa、Parallel、You.com、DuckDuckGo 或 Reddit
3. 看一眼那一行的费用说明，点「保存设置」
4. 让 agent 搜点东西

所有后端默认关闭，不保存就一个请求都不会发出。想绕开 agent 单独验某一家通不通，用「试搜与诊断」页签：它明确发一次真实请求，把结果和失败原因原样显示出来。

## 加 Key

`key` 或 `session` 模式的后端需要凭证。把 Key 填到那一行的凭证输入框再保存，插件会把它存进 DSH 的凭据库，名字在代码里固定，所以配置文件没办法把某次查询指向别的密钥。配置文件本身不保存 Key。

## 后端与费用

列表按**每家最便宜的用法**分组，所以有完全免费路径的永远排在最前面。每行用 chip 标出**所有**模式各自的费用档，当前选中的那个高亮。

| 分组 | 有哪些 | 说明 |
| --- | --- | --- |
| **有完全免费的用法** | Keenable、AnySearch、Exa、Parallel、You.com、DuckDuckGo、Reddit | 不用注册、不用 Key，开箱可用 |
| **自带账号** | X | 用你自己 X 网页端的 cookie，不花钱，但 X 改动页面里内嵌的接口时会失效 |
| **自托管** | SearXNG、open-websearch、小红书（Xiaohongshu） | 自己跑服务，额度由你自己定；小红书走的是你自己托管的浏览器 |
| **免费额度** | Linkup、Tavily、Brave、知乎（网页/站内）、百度、豆包 | 注册拿 Key，额度内免费 |
| **试用额度** | Serpex | 一次性试用额度，用完转付费 |
| **付费** | Mojeek、Anthropic、OpenAI、DeepSeek、腾讯 WSA | 按量收费，开之前先看单价 |

- 默认**全部关闭**，一个都不会自动启用
- 各家的具体额度、单价、来源链接和核实日期见 [docs/BACKENDS.md](docs/BACKENDS.md)

## 小红书

小红书只认自己的页面运行时，没有能直接调的 HTTP 接口，所以它走你自己托管的浏览器：不按次计费，成本就是那台跑浏览器的机器。

1. 按 [packages/core/image](../core/image/README.zh.md) 起浏览器容器，启动日志会打印端点和令牌
2. 打开 `http://<host>:6080/vnc.html`，在那扇已经开着的窗口里登录小红书。容器每分钟把登录态写进磁盘
3. 打开 **设置 → 网页搜索 → 搜索后端**，填「共享浏览器」那一段：端点（`ws://<host>:3000/ws`）、会话文件（可留空）、读取超时、同站点并发读取数；再把启动日志里的令牌填进「端点令牌」
4. 把小红书后端的模式设为 browser，启用并保存

令牌保护的是浏览器端点，不是网站账号，所以它按浏览器存一份，不按后端存。共享端点优先于后端自己的端点，后端里那个只在共享端点留空时兜底。会话文件必须和容器写的是同一个文件，否则每次读回来都是未登录。插件本身没法登录，登录永远留在那个浏览器的主人手里。

同站点并发读取数限制的是同一个站点上同时跑几个浏览器读取，这和「搜索行为」里的全局并行数量不是一回事：后者限制的是一次搜索同时问几家后端。遇到 429 限流后，本次浏览器会话会保守降到 1。

## 工具

- `web_search` — 上面说的多后端搜索。
- `web_search_plus` — 按本次调用指定搜索策略：`mode`（单后端/并行）、`backends`（从已启用里挑子集）、`allBackends` + `exclude`（全用但排掉几家）、`compact`（只回标题和链接，省结果 token）和 `maxResults`。只影响这一次调用，不改配置；没启用的后端会被明确告知而不是被悄悄忽略，实际用了哪些也会回显。可在设置里关闭。
- `x_thread` — 读一条 X 推文及其回复；需要 X 后端处于会话模式，深度、回复条数和字符预算都有上限。
- `xiaohongshu_note` — 读一篇小红书笔记：正文、作者、赞藏评转、标签、配图，需要的话再读一层评论。吃分享链接（里面带着读取要用的 token）或本次会话里搜到的笔记 id；需要小红书后端处于 browser 模式且共享浏览器端点已配置。
- `reddit_thread` — 读某个 Reddit 帖子的完整评论树；按深度、评论条数和字符预算截断。
- `search_manage` — 从 agent 侧查看或修改本插件自己的设置，包括共享浏览器令牌（`scope: browser`）而不只是某个后端的凭证。

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 搜不出东西 | 后端在你保存之前都是关闭的。去「搜索后端」启用一家再保存。 |
| 小红书报未登录 | 浏览器容器的登录态丢了。打开 noVNC 页面重新登录，下次读取会重新加载会话文件。 |
| 小红书报没有端点 | 填「共享浏览器 → 端点」，或者填该后端自己的端点。 |
| 某家返回限流 | 那家拒绝了这次请求。等一会儿，或在它那一行调低每分钟上限。 |
| 提示「配置版本冲突」 | 另一个窗口先保存了。刷新页面后重新提交你的修改。 |
