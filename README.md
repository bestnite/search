# dsh-search

A planned multi-backend search plugin for DeepSeek Harness, with explicit access modes, transparent cost tiers, and complete Web configuration.

## Status

Planning only. No runtime plugin has been implemented or installed. The existing search plugin remains unchanged.

See [the implementation plan](docs/PLAN.md) for the agreed requirements and acceptance criteria.
